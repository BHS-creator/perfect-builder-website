Last updated: 5 September 2026

Our accessibility approach

We aim to make this website usable across modern mobile phones, tablets and desktop devices. The site uses responsive layouts, readable contrast, keyboard-accessible links and controls, alternative text for images where available, and labelled navigation.

Known limitations

Some third-party content and legacy page content may not provide the same accessibility experience as the main website. We continue to review the website and improve issues where practical.

Need help accessing information?

If you have difficulty using any part of this website or need information in another accessible format, contact info@perfectbuilders.uk or call 07391 931969.

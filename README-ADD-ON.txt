PERFECT BUILDING CONTRACTOR — SEO / AEO / GEO ADD-ON
======================================================

Purpose:
This package adds search-focused pages and machine-readable supporting files
WITHOUT deleting or replacing the existing website files.

ADD THESE FILES TO THE ROOT OF YOUR GITHUB WEBSITE:
  seo/faqs-sheffield.html
  seo/areas-we-cover.html
  seo/business-information.html
  schema/faq-schema.json
  sitemap-seo.xml
  llms.txt

IMPORTANT:
1. Keep your existing index.html, CSS, JS, images, sitemap.xml and other pages.
2. Do NOT replace the existing sitemap.xml with sitemap-seo.xml.
3. After publishing, submit sitemap-seo.xml separately in Google Search Console.
4. llms.txt is supplementary and is NOT a ranking guarantee.
5. The FAQ page contains the visible content represented by faq-schema.json.
6. No claim in this package guarantees Google rankings or AI citations.
